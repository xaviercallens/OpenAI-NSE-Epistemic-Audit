# 02_Empirical_Observation — early toy models and the physical-metrics audit

> **Status (v5.5.0).** This folder holds the project's **early** numerical explorations. Earlier versions of this page
> said they "prove that manufactured singularities are unstable, non-generic mathematical artifacts" and that a
> "Dual-Scale metric" aborts the Euler cascade. Those claims are withdrawn: the scripts are low-dimensional toy models
> that *illustrate* questions (phase coherence, triad geometry), not proofs about OpenAI's construction, which is a
> correct theorem. The "Dual-Scale" cutoff is a modified equation; a bound on it says nothing about Euler or
> Navier–Stokes. The project's validated simulations are in
> [`05_Community_Research_Directions/`](../05_Community_Research_Directions/README.md) and are regenerated by
> [`BENCHMARKS.md`](../BENCHMARKS.md).

## Section 1: physical metrics of the construction

## Toy models

*   **`simu_sign_fragility_1D.py`**: a Katz–Pavlović / Desnyansky–Novikov dyadic shell model integrated with SciPy's
    implicit Radau solver. It asks how robust a cascade is to phase perturbation in that *scalar model*; the script's
    own revision note records an earlier hard-coded summary table and an unreachable threshold, both corrected. It does
    not establish anything about the 3D equations. (Relevant open question: whether thermal noise destroys the phase
    coherence the Euler construction needs — paper §7, Direction 3.)
*   **`simu_frustration_Z3.py`**: statistics of the Leray projection $\mathbb{P}(k)=I-(k\otimes k)/|k|^2$ over
    divergence-free wavevector triads on $\mathbb{Z}^3$ (a "frustration index"). A geometric illustration, not a
    regularity argument — Tao (2016) shows that estimates of this kind cannot by themselves exclude blow-up.
*   **`euler_counterdetonation/`** *(historical)*: a three-variable Rust ODE envelope of a cascade with an imposed
    cutoff $R_{\text{eff}}=\max(R,\alpha'/R)$. The cutoff's saturation is built into the model; it is not a simulation
    of OpenAI's Euler construction and the "dual-scale" motivation is withdrawn.

## Execution

```bash
python3 simu_sign_fragility_1D.py
python3 simu_frustration_Z3.py
cd euler_counterdetonation && cargo run --release    # historical toy
```
